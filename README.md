# End-to-End Sentiment Analysis using DistilBERT

An end-to-end sentiment analysis application built using **PyTorch**, **Hugging Face Transformers**, **FastAPI**, **Docker**, and **GitHub Actions**.

## 🚀 Project Status

🚧 Project is currently under development.

## 🎯 Goal

Build a production-ready sentiment analysis application that:

- Fine-tunes a DistilBERT model
- Provides real-time predictions through a FastAPI REST API
- Uses Docker for containerization
- Automates CI using GitHub Actions
